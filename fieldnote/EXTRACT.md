# Extracting this into its own repository

This directory is a complete, self-contained repository that currently lives
inside the `ZanCo` repo. It was built here because the GitHub App available to
the session that created it could not create repositories — not because it
belongs here.

Nothing outside `fieldnote/` is referenced. All paths, workspace globs, the
Dockerfile build context and the CI workflow assume this directory is the
repository root.

## Extract it

```bash
# From the ZanCo repository root, on the branch holding this work.
git subtree split --prefix=fieldnote -b fieldnote-standalone

# Create an empty repository on GitHub first (no README, no .gitignore), then:
git push git@github.com:<owner>/fieldnote.git fieldnote-standalone:main
```

Then clone it fresh and confirm it stands on its own:

```bash
git clone git@github.com:<owner>/fieldnote.git
cd fieldnote
pnpm install
pnpm build
pnpm check
```

## After extraction

1. **CI starts working.** `.github/workflows/ci.yml` only runs when it sits at
   the repository root, so it has never executed in its current location. Expect
   to fix a small number of things on the first green run — that is the workflow
   doing its job.

2. **Add the repository secrets** CI needs:
   - `ANTHROPIC_API_KEY` — for the eval job.

3. **Generate a lockfile.** `pnpm install` writes `pnpm-lock.yaml`; commit it.
   CI uses `--frozen-lockfile` and will fail without one.

4. **Set branch protection** on `main` requiring the `static`, `unit` and `rls`
   jobs. The RLS job is the one that matters — it proves cross-org isolation
   fails closed, and merging past it is how a tenancy bug ships.

5. **Delete `fieldnote/` from the ZanCo repository** once the extraction is
   verified, so there is exactly one copy.

## What is not included

- `pnpm-lock.yaml` — generated by the first `pnpm install`.
- Eval fixtures — these are real client documents about real properties and
  require written consent plus redaction. See `evals/fixtures/README.md`.
- Any secret. `.env.example` documents every variable; none has a real value.
